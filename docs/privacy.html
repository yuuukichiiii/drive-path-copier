Privacy Policy

Effective date: November 7, 2026

This Privacy Policy explains how Drive Path Copier (the "Extension"), a Google Chrome extension, accesses, uses, stores, and shares data, including Google user data obtained through Google APIs. The Extension is developed and maintained by an individual developer (contact: tanaka.yuki.dev@gmail.com).

1. What the Extension does

When you open a folder in Google Drive in your browser and click the Extension's button, the Extension builds the Windows Explorer path of that folder as it appears under Google Drive for desktop (for example, G:\Shared drives\Project\Folder) and copies it to your clipboard. This is the Extension's single purpose.

2. Google user data the Extension accesses

DataOAuth scopeWhy it is needed
Metadata of the Google Drive folder you are currently viewing and of its parent folders: folder name, parent folder IDs, and shared drive ID; and the name of the shared drive https://www.googleapis.com/auth/drive.readonly To reconstruct the folder hierarchy from the open folder up to the root, which is required to build the path
Email address of the signed-in Google account https://www.googleapis.com/auth/userinfo.email To choose the drive letter (G:, H:, ...) you assigned to that account

The Extension only requests metadata of the specific folder you have open and its ancestors, and only when you click the button. It never reads, downloads, creates, modifies, or deletes the contents of any file, and it does not list or search your other files.

3. How Google user data is used

Google user data is used only to generate the folder path you requested and to select the drive letter for your account. It is not used for any other purpose, including advertising, analytics, profiling, determining creditworthiness, or developing, improving, or training generalized artificial intelligence or machine learning models.

4. Storage and retention

  • Folder metadata is processed only in memory inside the Extension's popup and is discarded when the popup closes. It is never saved.
  • The generated path is written to your clipboard only when you click the button.
  • Email address: the address returned by Google is used only to look up your drive-letter setting and is not saved by the Extension.
  • Drive-letter settings (pairs of an email address and a drive letter that you enter yourself) are stored in Chrome's extension storage (chrome.storage.sync), which Chrome may sync across your own signed-in browsers. They remain until you delete them or uninstall the Extension.
  • Folder-name settings (the names used for "My Drive" and "Shared drives" in the path, which you can change to match your Windows language) are stored the same way. They contain no Google user data.
  • OAuth access tokens are issued and cached by Chrome's built-in identity API and are not stored separately by the Extension.

5. Sharing and transfer

The Extension has no servers. No Google user data or any other data is transmitted to the developer or to any third party. The only network communication is between your browser and Google's APIs (www.googleapis.com) over HTTPS, made solely to retrieve your own data as described above. Data is never sold, rented, or shared.

6. Limited Use disclosure

Drive Path Copier's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Security

All requests to Google APIs use HTTPS. Access to Google Drive is read-only and limited to folder metadata. Because no data is stored outside your browser, there is no external database that could be breached. The full source code is public on GitHub, so its behavior can be audited.

8. Your choices and data deletion

  • You can revoke the Extension's access to your Google account at any time at https://myaccount.google.com/permissions.
  • You can delete drive-letter settings from the Extension's settings screen (gear icon).
  • Uninstalling the Extension removes all data it stored in your browser.

9. Children

The Extension is not directed at children under 13 and does not knowingly collect data from them.

10. Changes to this policy

Any changes will be posted on this page with an updated effective date.

11. Contact

Questions about this policy: tanaka.yuki.dev@gmail.com

プライバシーポリシー

施行日：2026年11月7日

本ポリシーは、Google Chrome 拡張機能 Drive Path Copier（以下「本拡張機能」）が、 Google API を通じて取得する Google ユーザーデータを含むデータを、どのように取得・利用・保存・共有するかを説明します。 本拡張機能は個人の開発者が開発・運営しています（連絡先：tanaka.yuki.dev@gmail.com）。

1. 本拡張機能の機能

ブラウザで Google Drive のフォルダを開いた状態でボタンを押すと、そのフォルダを Google ドライブ（パソコン版）で開く場合の Windows エクスプローラーのパス（例：G:\共有ドライブ\プロジェクト\フォルダ）を組み立て、クリップボードにコピーします。 これが本拡張機能の唯一の目的です。

2. 取得する Google ユーザーデータ

データOAuth スコープ必要な理由
現在開いている Google Drive フォルダおよびその親フォルダのメタデータ（フォルダ名、親フォルダ ID、共有ドライブ ID）と、共有ドライブ名 https://www.googleapis.com/auth/drive.readonly 開いているフォルダからルートまでの階層をたどり、パスを組み立てるため
ログイン中の Google アカウントのメールアドレス https://www.googleapis.com/auth/userinfo.email そのアカウントに割り当てたドライブ文字（G:、H: など）を選ぶため

取得するのは、ボタンを押したときに開いているフォルダとその上位フォルダのメタデータのみです。 ファイルの内容の閲覧・ダウンロード・作成・変更・削除は一切行わず、他のファイルの一覧取得や検索も行いません。

3. Google ユーザーデータの利用目的

Google ユーザーデータは、要求されたフォルダパスの生成と、アカウントに対応するドライブ文字の選択のみに使用します。 広告、分析、プロファイリング、信用力の判断、汎用 AI・機械学習モデルの開発・改善・学習を含む、その他の目的には一切使用しません。

4. 保存と保持期間

  • フォルダのメタデータ：拡張機能のポップアップ内のメモリ上でのみ処理し、ポップアップを閉じると破棄します。保存しません。
  • 生成したパス：ボタンを押したときにのみクリップボードへ書き込みます。
  • メールアドレス：Google から返されたアドレスはドライブ文字設定の照合にのみ使い、本拡張機能は保存しません。
  • ドライブ文字の設定（ユーザー自身が入力したメールアドレスとドライブ文字の組）：Chrome の拡張機能ストレージ（chrome.storage.sync）に保存され、ユーザー自身のログイン済みブラウザ間で同期される場合があります。削除するかアンインストールするまで保持されます。
  • フォルダ名の設定（パスに使う「マイドライブ」「共有ドライブ」の名前。Windows の表示言語に合わせて変更可能）：上記と同じ場所に保存します。Google ユーザーデータは含みません。
  • OAuth アクセストークン：Chrome 標準の identity API が発行・キャッシュし、本拡張機能が別途保存することはありません。

5. 共有と転送

本拡張機能はサーバーを持ちません。Google ユーザーデータを含むいかなるデータも、開発者や第三者に送信しません。 通信は、上記のとおりユーザー本人のデータを取得するための、ブラウザと Google API（www.googleapis.com）間の HTTPS 通信のみです。 データの販売・貸与・共有は行いません。

6. Limited Use（限定的使用）に関する開示

Drive Path Copier が Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）を遵守します。

7. セキュリティ

Google API への通信はすべて HTTPS で行います。Google Drive へのアクセスは読み取り専用で、フォルダのメタデータに限られます。 ブラウザ外にデータを保存しないため、漏えいの対象となる外部データベースは存在しません。 ソースコードはすべて GitHub で公開しており、動作を確認できます。

8. ユーザーの選択とデータの削除

  • Google アカウントへのアクセス許可は、https://myaccount.google.com/permissions からいつでも取り消せます。
  • ドライブ文字の設定は、拡張機能の設定画面（歯車アイコン）から削除できます。
  • 拡張機能をアンインストールすると、ブラウザに保存したデータはすべて削除されます。

9. 子どもについて

本拡張機能は 13 歳未満の子どもを対象としておらず、子どものデータを意図的に収集することはありません。

10. ポリシーの変更

本ポリシーを変更する場合は、施行日を更新したうえで本ページに掲載します。

11. お問い合わせ
